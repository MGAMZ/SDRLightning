📖 如何读这张图（点开/折叠）

三张图从上到下：

  • 包络轨迹：flash 触发前后共 ~1.4 s 的 \|IQ\| 包络起伏。横轴 0 ms 是触发时刻；左侧是 pre-trigger，右侧是 post-trigger。黄色虚线标峰值位置。
  • 窗口平均频谱：整段捕获 IQ 的 FFT 平方在频域上做平均 (power spectrum)，256 bin 下采样到显示宽度。反映 flash 期间能量在频域上的分布。
  • 峰值附近 IQ 切片：峰值 ±25 ms 的原始 IQ 同相/正交分量 + \|IQ\| 包络，让你看清载波波形。

关键定义：

  • Tw（窗长）：每 Tw 算一次窗内 \|IQ\|² 均值 I_k
  • Tb（baseline 时长）：回看 Tb 内的 I_k 求 baseline
  • Δ（触发阈值）：I_k − baseline > Δ 触发
  • Tpre/Tpost：触发前后保存的包络/IQ 长度

典型 flash 形状：

  • 单峰：近距离闪电单次放电
  • 多峰串：远距离多回击闪电 (3-5 个突起，间隔 ~50 ms)
  • 缓升缓降：噪声或非闪电干扰
